# e-your-effect

Replace this template when you add a real effect. Write instructions an agent can follow without credentials or private local paths.

## When to use

One or two sentences on the look or sound this effect adds (for example a transition, confetti, fireworks, a caption style, an overlay, a sound effect, or a music bed).

## Steps

1. Read the declared inputs from `effect.yaml`.
2. Apply the effect, calling any scripts in `scripts/` by relative path.
3. Write the declared outputs.
4. Leave a preview (see `PREVIEW.md`) that shows the result.

## Checks

Name what “done” looks like (the effect is visible or audible, duration is unchanged unless the effect is meant to change it, and so on).
