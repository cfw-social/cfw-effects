# Preview

Every effect pull request should include a short preview so an admin can judge the look or sound without running the effect.

Add one of these next to this file, named so it is obvious:

- `preview.gif` or `preview.mp4` for motion (transitions, confetti, fireworks, caption styles)
- `preview.png` for a still overlay or a caption frame
- `preview.mp3` or `preview.wav` for a sound effect or music bed, plus a one-line note below of duration and mood

Until you have a real preview, do not leave a fake or placeholder media file in the folder. Describe in the pull request what the preview will show, then attach the real file before review.

Replace this file's body with a caption for the preview once the media is added (what it shows, the variation, and anything a reviewer should listen or look for).
