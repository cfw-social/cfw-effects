# Recipes

CFW Studio recipes. Each recipe is a `p-*` folder: a guiding document (`SKILL.md`) plus `recipe.yaml`, which lists the blocks it uses, the union of their required inputs, and the final output.

Start a new recipe from [`_template/`](_template/). If the recipe needs a block that does not exist yet, add that block in the same pull request. See [../docs/DESIGN.md](../docs/DESIGN.md) for the proposed format, including the planned `p-reels-clipper` composition. This folder is a scaffold; there are no production recipes in this repository yet.
